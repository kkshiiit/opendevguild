## B. Architecture

A selects and plans; B supplies bounded specialist procedures; C is the existing
host/runtime; D reviews evidence and may reject an executor. Six lifecycle states
are distinct from six quality gates. FAST/STANDARD/CRITICAL control proportional
work without increasing authority. The visual library reuses core UX/UI,
accessibility, implementation, performance and evaluation owners. No new permanent
visual subagents were created. Human corrections are manually reviewed procedural
knowledge, not automatic model training.

## H. Use

Selectively copy skill folders into the target repository's `.agents/skills/`,
refusing collisions. Native profiles are optional under `.codex/agents/`. The
bilingual README includes personal/project installation, update/uninstall and
verification. Do not copy this repository's contributor AGENTS.md into an app.

```text
$mission-control Fix only the booking layout. Use the existing stack, inspect
rendered evidence and select only relevant visual procedures. Do not deploy.
```

```bash
uv sync --frozen --group visual
uv run --frozen python scripts/guild.py validate
uv run --frozen python scripts/visual.py validate
uv run --frozen python -m unittest discover -s tests -v
```

scope, sequence, expected results, controls and limits. Original browser fixtures
are runnable; native recipe commands are not misrepresented as executed runs.
